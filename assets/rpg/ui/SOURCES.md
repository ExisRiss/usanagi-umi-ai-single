# RPG visual sources

Runtime item illustrations in `assets/rpg/items/` are original Usanagi vector artwork created for this project and do not depend on remote URLs.

Research references for optional third-party UI assets:

- Kenney UI Pack (RPG Expansion): Creative Commons CC0 — https://kenney.nl/assets/ui-pack-rpg-expansion
- Kenney Fantasy UI Borders: Creative Commons CC0 — https://kenney.nl/assets/fantasy-ui-borders
- OpenGameArt RPG UI Elements CC0: CC0 — https://opengameart.org/content/rpg-ui-elements-cc0
- OpenGameArt RPG UI Icons: CC0 — https://opengameart.org/content/rpg-ui-icons

Third-party assets are not required at runtime, so Usanagi does not depend on a live external asset URL.
